19. Batch Processing Engineer 
Job Summary 
The Batch Processing Engineer designs and manages large-scale batch data processing 
workflows for analytics and reporting. 
Key Responsibilities 
• Develop batch data processing pipelines using Spark or Hadoop 
• Schedule and monitor batch jobs 
• Optimize batch job performance and resource utilization 
• Manage data dependencies and workflows 
• Ensure data accuracy and completeness 
Required Skills 
• Strong Spark or Hadoop experience 
• SQL and data transformation expertise 
• Workflow orchestration tools (Airflow, Oozie) 
• Linux and scripting skills 
Qualifications 
• Bachelor’s degree 
• 3–6 years of batch processing experience
